# 3D-рендерер

Простой 3D-движок рендеринга, написанный на C++. Этот рендерер включает растеризацию треугольников, трансформацию, управление камерой и базовый Z-буфер.

## Возможности

- Отрисовка 3D объектов на пиксельный экран
- Интерактивное управление камерой (перемещение и вращение)
- Z-буфер для корректной обработки глубины
- Базовое управление сценой
- Корректная перспективная проекция
- Клиппинг треугольников

## Сборка проекта

### Предварительные требования

- CMake (версия 3.24 или выше)
- Компилятор C++ с поддержкой C++17
- Библиотека Eigen3 (включена как подмодуль)
- Библиотека SFML (загружается автоматически через CMake)

### Инструкции по сборке

1. Клонируйте репозиторий с подмодулями:
   ```
   git clone --recurse-submodules https://github.com/a-ri-sha-sha/3D_Renderer.git
   git checkout dev
   git submodule update --init --recursive
   cd 3d-renderer
   ```

2. Установите зависимости для SFML:
    ```
    sudo apt update
    sudo apt install \
        libxrandr-dev \
        libxcursor-dev \
        libudev-dev \
        libopenal-dev \
        libflac-dev \
        libvorbis-dev \
        libgl1-mesa-dev \
        libegl1-mesa-dev \
        libdrm-dev \
        libgbm-dev \
        libfreetype6-dev
    ```

3. Создайте директорию для сборки и перейдите в неё:
   ```
   mkdir build
   cd build
   ```
   

3. Сгенерируйте файлы сборки с помощью CMake:
   ```
   cmake ..
   ```

4. Соберите проект:
   ```
   make
   ```

5. Запустите рендерер:
   ```
   ./Renderer/3d-renderer
   ```

## Управление

### Перемещение камеры

- W - Движение вперед
- S - Движение назад
- A - Движение влево
- D - Движение вправо
- Пробел - Движение вверх
- Левый Shift - Движение вниз

### Вращение камеры

- Правая кнопка мыши + Движение мыши - Вращение камеры
  - Горизонтальное движение мыши - Рыскание (горизонтальное вращение)
  - Вертикальное движение мыши - Тангаж (вертикальное вращение)

### Управление сценой

- 1 - Переключиться на базовую сцену с треугольником
- 2 - Переключиться на сцену со сферами
